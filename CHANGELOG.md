# Changelog

All notable changes to PlanSeal are documented here.

## Unreleased

### Changed

- Added a conversion-focused 2:1 PlanSeal campaign banner that frames the skill as an execution-readiness gate, remains legible in shared-link previews, and distinguishes sealed `Ready` plans from returned drafts.
- Rebuilt both README openings around the product promise, three core guarantees, a 60-second quick start, and a concrete output contract.
- Reduced repeated usage copy and made the relationship to optional frameworks, models, and companion skills visible before the detailed method.

## 0.1.0 - 2026-07-16

### Added

- Initial public release of the `$planseal` skill.
- Mandatory GORE core for Focused, Standard, Migration, and Master plans.
- Evidence taxonomy, repository freshness checks, and execution preflight.
- Target behavior contracts, work-package DAGs, verification design, rollback, cleanup, and handoff guidance.
- `Ready`, `Needs Revision`, and `Not Executable` verdicts.
- Version-pinned installation runbook, manifest, smoke tests, trust documentation, and bilingual README files.
