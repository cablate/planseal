# Changelog

All notable changes to PlanSeal are documented here.

## 0.1.0 - 2026-07-16

### Added

- Initial public release of the `$planseal` skill.
- Mandatory GORE core for Focused, Standard, Migration, and Master plans.
- Evidence taxonomy, repository freshness checks, and execution preflight.
- Target behavior contracts, work-package DAGs, verification design, rollback, cleanup, and handoff guidance.
- `Ready`, `Needs Revision`, and `Not Executable` verdicts.
- Version-pinned installation runbook, manifest, smoke tests, trust documentation, and bilingual README files.
